# Circuit layout assets

White-outline SVGs from Jules ROY's f1-circuits-svg project, recovered from
https://github.com/MisterSix2295/f1-circuits-svg at commit
`f758ce80bb2f9af014eba35d975436381ce3cba9` (MIT; license included with assets).
Source directory: `circuits/white-outline/`.

The app bundles these files and embeds them as SVG image data URIs. Rendering
does not require a GitHub request from the browser. A `viewBox="0 0 500 500"`
was added to preserve the source dimensions when resizing.

Monza's modern 2000-onward layout is `monza-6` in this snapshot, and Monaco's
modern 2003-onward layout is `monaco-5`. The old remote mapping used unavailable
`monza-7` and `monaco-6` URLs.
